# Bin2Dec

A simple binary-to-decimal converter built with plain HTML, CSS, and JavaScript.

App made for the challenge [App Ideas](https://github.com/florinpop17/app-ideas)

## Files

- `index.html` — The main page markup that contains the input field, result display, breakdown panel, and clear button.
- `style.css` — Styling for the app, including layout, responsive design, and dark mode support.
- `script.js` — Binary validation, conversion logic, and rendering of the bit breakdown.

## Features

- Converts binary input into a decimal value in real time.
- Displays an error message for invalid characters.
- Shows a detailed breakdown for each bit value.
- Includes a clear button to reset the input and output.

## Usage

1. Open `index.html` in a web browser.
2. Enter up to 8 binary digits (`0` or `1`) in the input field.
3. The decimal result appears immediately below the input.
4. Click "Clear" to reset the form.

## Notes

- The app only accepts binary digits (`0` and `1`).
- Invalid input shows an error message and hides the breakdown.

## Development

No build tools are required. This is a static frontend project, so you can run it directly from the filesystem or a simple local server.
